# 装配组件清单

先读 [工具接口约定](../../../docs/TOOL_CONTRACTS.md)。`sw_component_tree` 目前待实现；不得将流程说明当作已存在的 API。

1. 在已具备连接能力的目标电脑检查实际工具列表。缺少工具时报告缺口；任务明确要求开发或修复时，按 [开发计划](../../../docs/DEVELOPMENT_PLAN.md) 实现本功能，不在 skill 目录写程序。
2. 读取活动文档信息。仅对装配文档请求组件树；若 STEP 导入成多实体零件，报告真实类型，不能输出空装配冒充成功。
3. 调用 `sw_component_tree`，核对返回的文档、配置与目标一致。直接复用会话/文档工具即可，不要求加载其他 skill 的完整流程。
4. 检查实例路径、父子关系、名称、文件路径和读取状态。同一零件的多个实例分别保留；抑制、轻化或未解析节点不可静默丢弃。遍历不完整时保留错误并标明部分结果。
5. 将工具返回的 JSON 原样保存到仓库根目录下 `outputs/solidworks_inventory.json`；已有结果时用新文件名。只保存实际返回值，不手工补齐未知组件、状态或路径。
6. 与 SolidWorks 模型树核对根装配和若干实例。汇报统计口径、是否包含子装配节点、未解析数量与实际核对结果；没有人工核对就明确标记未核对。

只交付组件清单。几何、配合、运动副和行程留给后续独立功能。
