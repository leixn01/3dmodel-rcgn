# 目标实例图

输入：原始chain dossier，可选独立圆柱关系文件。输出：outputs下新的target graph。

1. 已有完整来源时调用cad_build_target_graph；连接证据绑定的圆柱关系会自动读取，无需重复指定。
2. 没有链清单时只交接其必要输入给链级汇总能力，不强制重采已有SolidWorks数据。未知关系保留，继续可独立完成的分析。
3. 报告实例数、正向证据对、单一轴向覆盖、flags及来源缺口；一个实例不是已确认刚体，support不是概率。
4. 将结果文件交给独立模板匹配能力。不要按名称补关节，不等待人工复核。

需要来源规则、单位或失败处理时读[图适配说明](references/target.md)。不预加载匹配算法和全部采集入口。
