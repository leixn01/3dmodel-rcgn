# 几何关系候选

输入：完整空间清单、2–32 份实例圆柱原始返回及明确公差。输出：同轴/平行候选新文件。

1. 调用离线 cad_component_relations，显式传毫米/度公差。缺少项目公差的探索可用 0.1 mm、0.1°，必须标明为探索值。
2. 检查源哈希、范围、complete/comparison_complete/truncated；EVIDENCE_MISMATCH 时重新核对来源，不改数据骗过校验。
3. 结果只覆盖所给实例；无限轴相符不证明有限面接触，分割面配对数不是连接数。保持 requires_review，不调用配合采集或自动确认运动副。

仅在不确定参数、字段含义或遇到失败时读取 [细节与分支](references/details.md) 的对应段落；常规调用按 MCP Schema，不预加载参考文件或其他 skill。引用其他能力时只交接所需输入/输出。
