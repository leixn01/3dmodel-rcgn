# SolidWorks 会话检查

先读 [工具接口约定](../../../docs/TOOL_CONTRACTS.md)。其中 SolidWorks 工具目前待实现；skill 文件存在不代表连接能力已经可用。

1. 确认实际运行位置。目标是已安装 SolidWorks 的 Windows 本机；当前环境若不是该电脑，只能进行离线开发与检查。
2. 检查 Agent 当前工具列表，按工具描述识别 `sw_session_status`、`sw_active_document`；MCP 客户端可能附加服务名前缀，不硬编码前缀。
3. 工具可用时先查询会话，再读取活动文档。核对 SolidWorks 版本、文档标题、路径、类型和活动配置；没有文档与读取失败分别报告。
4. 工具缺失时明确报告缺口。仅当任务包含开发或修复时，按 [开发计划](../../../docs/DEVELOPMENT_PLAN.md) 实现连接工具及其 MCP 注册；普通使用请求不自动变成开发任务，不用临时 COM 脚本绕过工具边界。
5. 不自动启动新 SolidWorks 实例，不自动打开、切换、保存或关闭模型。多实例不能明确定位时报告歧义。
6. 输出实际调用结果及验证层级；模拟测试不算已连接成功。组件清单属于独立功能，不能用文件体检结果替代。
