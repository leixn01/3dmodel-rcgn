# 查找结构参考

输入：可选功能关键词。输出：模板ID、来源、数据划分和已标注结构范围。

1. 调用 cad_list_mechanism_templates；无合适关键词时列出全部参考项，不能将标签命中当作目标机构识别。
2. 默认不使用 heldout；只有明确评测任务才 include_heldout=true，记录是否接触过测试模板。
3. 根据已记录的关节数量说明可用性；没有关节的模型保留为信息不足样例。
4. 需要具体结构时只交接 template_id 给提取能力；缺少匹配资产时继续保留未知和风险，不等待人工判断。

需要词表、划分或来源说明时读 [目录说明](references/catalog.md)。不要预加载提取或比较流程。
