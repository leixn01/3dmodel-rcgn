# 有限面边界分支

仅在已有原始finite报告时传finite_analysis_path；与其它profile互斥。输出v7计划，只采指定圆柱面的解析边界，单面去重、完整保护/预算保留。缺面目录先回独立目录/面探测规划，不在此工具补猜索引。

必须同check/target和报告的exact index；新index先重算finite报告。默认max_edges=64不可通过自动换参数重试，failed/partial记录和共享四轮不变。预算最低可容一面5调用；两实例两面8调用。

批次→同check索引→原geometry报告加新index重算finite报告→新计划。旧证据与结果不覆盖，停止不等于机械确认。未知物理啮合、角向裁剪、限位和运动能力在结论保留。
