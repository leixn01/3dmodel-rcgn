# 约束缺口规划（0.23）

cad_plan_evidence_tasks仍必填draft_check_path、output_path；可选constraint_analysis_path启动algorithm_version=4、plan_kind=target_constraint_gaps。报告和check必须绑定同一target graph。已有索引传evidence_index_path；报告自身绑定索引时自动继承，不允许换旧索引。v4首次也有continuation，停止时没有guard空转。

只对MATE_REFERENCE_GEOMETRY_MISSING_OR_UNSUPPORTED、CONCENTRIC_ROTATION_LOCK_UNKNOWN安排一次sw_mate_inventory(include_reference_geometry=true)。基本采集不满足增强能力；完整/部分增强来源或历史失败尝试都阻止重复增强。默认max_features=2000、max_mates=200、max_entities=16、max_depth=32，规划器不自动扩预算。

根配合调用保护目标范围内全部实例，N个实例需2N+3次工具调用。max_tasks仍默认20、范围3–200；不足整项延期，不能删保护步骤。continuation.reason明确区分CAPTURE_BUDGET_UNAVAILABLE、ROUND_LIMIT、PRIOR_ENHANCED_ATTEMPT_NO_AUTOMATIC_RETRY、ENHANCED_SOURCE_ALREADY_OBSERVED、MULTIPLE_MATE_SNAPSHOTS_NOT_COMBINED、NO_EXISTING_CONNECTION_BASIS等。基础与增强共用原索引的4轮上限。

constraint_findings列约束缺口，retained_constraint_conflicts和constraint_pair_flags保留冲突/来源歧义；remaining_findings仍保留原check发现。约束报告省略的实例对见constraint_coverage与output_truncated，不因没有出现在计划里就算已完成。STEP完整无配合、未实现的求解规则、已有增强但仍不支持的几何均停止重采，保留未知。

collect只交接evidence-task-execute。完整执行且guards_passed后交接evidence-reintegration；v4回填会另写新check、index及绑定索引的约束报告。再次规划使用这两份新check/report，或显式传其最新索引。partial/failed但保护通过的尝试也计轮数，不删历史、更换文件名或重复基础扫描来绕过停止。
