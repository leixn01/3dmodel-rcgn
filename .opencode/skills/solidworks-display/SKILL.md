# 辅助对象显隐

输入：目标文档 token、辅助类别和显示意图。输出：辅助类别开关回读结果。

1. 先读 sw_get_display_state，再用 sw_set_display_visibility 显式设置类别和 visible。
2. 核对类别开关与总屏蔽的影响；不为了显示一个类别擅自放开其他类别。
3. 基准面等类别过滤不等于单个特征可见性，窗口仍需核对；装配组件显隐由独立能力处理。

仅在不确定参数、字段含义或遇到失败时读取 [细节与分支](references/details.md) 的对应段落；常规调用按 MCP Schema，不预加载参考文件或其他 skill。引用其他能力时只交接所需输入/输出。
