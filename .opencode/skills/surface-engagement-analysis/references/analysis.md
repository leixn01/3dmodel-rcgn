# 来源与判读

cad_analyze_surface_engagement必填finite_analysis_path、output_path；可选evidence_index_path。默认继承finite报告索引；显式最新index须同目标且延续全部原历史。工具内部以新index重算finite依据，但不覆盖旧报告。输出完整文件、紧凑摘要，来源哈希和派生字段可重放。

每对仅在正的共同轴向包络内生成2个轴向站位（1/3、2/3）×8个45度方向的明确测点；每侧用自身圆柱生成坐标，不假设两侧UV对应。同面多对去重，最多32点，遗漏计数保留。采样命中不等于共同表面积；报告用min(原距离容差,0.01mm)统一重判query_to_face_distance_mm，保留原采样参数。

paired_samples保留每个查询是否齐全/双侧命中、内外侧相反、点间距离、法向相反；这些计数不是概率、配合率或接触面积。两个外表面不是轴孔互补，薄片不解释材料侧。即使16点全中也不证明完整360度或轴向连续覆盖。

adjacent_axial_planes只来自同体、真实共享边、身份核对通过的邻接平面；去掉选中圆柱自身/缝边。相向且轴向位置接近的邻面仍需有限端面重叠和接触证据，retention_confirmed=false。不存在行程/关节/碰撞结论。

只消费完整、保护通过的观测；partial/failed、竞争快照、缺来源、各层覆盖限制仍保留。输出新文件不可复用旧路径。
