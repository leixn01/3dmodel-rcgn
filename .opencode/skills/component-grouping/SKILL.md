# 角色候选

输入：已导出的完整空间清单。输出：叶实例角色候选新文件。

1. 调用离线 cad_group_components；需要范围时用完整 occurrence_path，不重采已有可靠输入。
2. 未知或冲突名称保留 pending；子装配容器不重复算作叶件，同文件实例不合并。
3. 输出候选、依据和不确定风险，继续可独立完成的分析，不等待人工确认，也不写成manual_confirmed。角色不证明刚体或运动副；本流程不采集配合或改CAD。

仅在不确定参数、字段含义或遇到失败时读取 [细节与分支](references/details.md) 的对应段落；常规调用按 MCP Schema，不预加载参考文件或其他 skill。引用其他能力时只交接所需输入/输出。
