# 文档操作

输入：明确的打开/导入/重建任务。输出：活动文档核对结果。

1. 打开模型调用 sw_open_document；用返回文档信息确认真实导入类型。
2. 仅在用户任务需要时用当前 token 调用 sw_rebuild；只读检查不顺带重建。
3. 不保存覆盖、不关闭已有文档。需要启动软件时交接给启动能力，不把启动写进文档工具。

仅在不确定参数、字段含义或遇到失败时读取 [细节与分支](references/details.md) 的对应段落；常规调用按 MCP Schema，不预加载参考文件或其他 skill。引用其他能力时只交接所需输入/输出。
