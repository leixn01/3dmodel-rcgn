# 比较机构图

输入：reference与candidate原始图文件、绑定两图哈希的body correspondence文件。输出：outputs下新的差异报告。

1. 已有合法对应文件时直接调用 cad_compare_mechanism_graphs，不重新提取图或启动CAD。
2. 对应不全时保留未映射实体；没有对应文件时报告该比较输入缺口，继续独立解析/整理已有证据。不要凭同名、数组索引或期望分数补造对应，也不等待人工确认。
3. 分别报告刚体覆盖、连接和关节类型指标、缺失/多余、排除项及来源风险。零分母为null。
4. 将轴线、限位、耦合与拆卸路径列为本工具未评估项；自比较或人工构造误差只验证解析/评分链路。

需要格式、映射规则或指标解释时读 [评分细节](references/scoring.md)。验收任务才读docs/MCP_ACCEPTANCE.md的0.13.0章节。
