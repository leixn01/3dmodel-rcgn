# 机构链证据清单

输入：完整空间文件、2–50个明确叶实例、范围名称及已有可选证据。输出：新的 chain dossier JSON。

1. 明确所选范围；依据用户指定或已知模型清单列出完整实例路径，不能从“三独立”等名称硬编码链路。
2. 调用 cad_build_chain_evidence；有分组/连接/近接触/面复核文件才传，缺失时允许生成保留未知的草案，不强制重跑采集。
3. 报告 members、全部 pairs、unknown、review_flags 和 boundary_evidence；范围外已知联系不能悄悄丢弃，未测不当作不连接。
4. 需要模板分析时，将清单交给独立目标实例图适配能力；review_flags按证据缺口处理，不等待人工确认。不确定处在结论给出未知、替代解释与风险，不把角色或相向测点直接认定为运动副。

准确参数、来源校验或差异解释需要时读 [汇总细节](references/details.md)。验收任务才读 docs/MCP_ACCEPTANCE.md 的0.12.0章节，不预加载其他 skill。
