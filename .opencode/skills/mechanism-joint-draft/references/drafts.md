# 草案说明

cad_draft_joints必填rigid_candidates_path、output_path；输入原始cad_build_rigid_candidates落盘文件。默认不加载模板；不传template_ids或传[]都生成目标证据草案。只有明确传1–8个ID才增加可选参考类比，include_heldout=false；明确评测才可启用heldout并记录暴露。无需合适模板也能检查、规划、补采、回填、比较。

0.21.0新草案algorithm_version=2。主结果partition_results[].connection_candidates包含组成员、原实例对、目标配合特征/几何/冲突和来源。assessment为constraint_feature_evidence、geometric_candidate、conflicting_evidence或insufficient_evidence；它们表示证据性质，不是已确认机械连接。target_joint_kind始终unknown、target_degrees_of_freedom=null，connection_confirmed=false。缺证据的组件对仍保留，不因匹配失败删除。

max_target_pairs默认200/范围1–2000，所有分组方案共享；优先返回有flags/较高证据排序权重的对，再按ID稳定排序。逐方案target_pair_coverage及总体target_pairs_truncated报告省略。没有模板时match=null、skip_reason=templates_not_requested属于正常流程，searched_partitions/evaluated_states为0；不能写“没有机构候选”。summary.target_pairs_returned是目标关系数量，returned_candidates是参考类比数量。

可选参数：pattern_size默认3/范围2–6，max_candidates默认5/范围1–10（每个分组方案），max_states默认20000/范围1–100000（全部方案共享），beam_width默认50/范围1–1000，angle_tolerance_deg默认10/(0,45]。相对轴角评分沿用模板匹配。

axis_distance_tolerance_mm默认0.1/(0,10]，axis_angle_tolerance_deg默认1/(0,5]，只用于合并几何轴线候选，不代表制造公差或接触精度。无向轴归一化后，取无限轴线上离根原点最近的点作比较。最多检查每条组间边128条轴关系（两端各一条观测），返回16条线候选，每条最多保留32条来源引用并标记source_list_truncated；发生计算截断不提供唯一axis_line_candidate。

每个partition先把组内成员保留为清单，组间连接取成员对支持最大值，不叠加条数。方向不一致或原来源轴已截断时代表方向为空。唯一轴线还要求全部参与关系为同轴、线位置/方向公差一致且无flags；这仍是几何候选，不证明关节。平行线可以提供方向线索，不能挑一条当唯一轴线。

读取partition_results：skip_reason为insufficient_eligible_groups时，当前方案不足请求的窗口大小；不暗自减小。需要两个刚体分析时用pattern_size=2重跑所有方案到新文件，避免跨不同窗口大小比较分数。partition_state_budget_zero表示分配不到状态预算。match包含candidates、template_rankings、best_score_ties_found、search_exhaustive和output_truncated；草案在candidates[].joint_hypotheses。

显式模板类比才有mapping，包含template_body_id、group_id和全部member_occurrence_paths。joint_hypotheses中的reference_joint_kind/reference_dof只描述参考；hypothesis_kind和target_joint_kind保持unknown，dof_hypothesis/target_degrees_of_freedom保持null。reference_compatibility=opposed_by_active_lock表示参考运动类型与目标lock特征相反，不是已由求解器证伪；其他情况not_established也不代表支持该类型。direction_candidate_root_unit和geometry仍为几何线索。axis_origin_m、limits、pitch_m_per_revolution保持null。所有joint_axis_verified/dof_verified/mechanical_relation_confirmed为false。

没有全局“最佳刚体分组”：各方案内排序，分数不能证明归属；不同成员数量的候选也不代表同一个机械范围。保留unmatched_group_ids、边界连接与分组文件的省略/冲突。search_exhaustive_within_retained_partitions仅指保留方案的有限窗口；partition_space_exhaustive始终false。

SOURCE_INCOMPLETE、RIGID_CANDIDATE_LIMIT、TARGET_PAIR_LIMIT保留部分输出；显式模板分析另有MATCH_SEARCH_LIMIT/NO_SUPPORTED_MATCH，但目标基线仍存在。EVIDENCE_MISMATCH应重新计算被改变来源后的依赖，不手改派生字段。输出只能新建，不覆盖证据。旧algorithm_version=1文件按旧规则重放；其中模板hypothesis_kind不能作为新目标结论，迁移时从同一rigid source重新生成默认草案。

CLI：`python -m cadkin draft-joints outputs/rigid.json --output outputs/target-draft.json`。可选类比另存新文件，增加`--template-ids bench_vise --pattern-size 2`；不要覆盖目标基线。不同模板不能改变同范围、同阈值、同目标预算下的connection_candidates。

已有执行历史时，生成新check后交接evidence-observation-index，用最新receipt重建绑定新check的索引，再规划续轮，保持原累计轮数；不能为了迁移版本省略索引或清空历史。
