# 当前进度与下一步

当前 MCP 0.7.0：20 个工具、14 个独立功能 skill。Windows + 已有 Conda 环境；OpenCode 使用当前环境的 python 启动 MCP。原始测试 STEP 保持不变。

## 现在能做到的效果

- 启动或复用 SolidWorks、打开模型，读取实例树、位置/变换/近似包围盒，控制选择、视图和显隐。
- 从完整空间清单生成叶实例角色候选，保留未知名称与人工复核；读取单实例固定/配合记录和零件定义圆柱面轴线。
- 新增 `cad_component_relations`：对选定实例的圆柱轴线生成同轴/平行候选，保存明确公差、角度/偏移、源文件哈希和可选角色上下文。离线计算，不创建 COM 对象。

这形成“读取事实 → 角色候选 → 几何关系候选 → 人工核对”的初步流程。仍不能自动确定刚体、运动副、行程或拆解顺序，也不移动零件。代码实现不等于已在用户 SolidWorks 上全部验收。

## 本轮验收

按 [0.7.0 清单](MCP_ACCEPTANCE.md#070组件关系候选) 在一条升降链上选择 2–5 个零件，保持模型不变，采集完整空间基准和各实例圆柱证据。先用项目公差；无公差时可用明确标记为探索值的 0.1 mm、0.1°。核对候选、部分来源、计算截断和文件来源。0.5.0 修复与 0.6.0 新读数的实机复测仍需完成。

## 下一步：连接证据与运动关系复核

1. 用真实验收结果纠正几何候选中的误报/漏报，保留源记录，不把分割圆柱面条数视为连接数。
2. 独立补充配合的活动/抑制状态和所属装配坐标上下文，让几何候选能与有效配合对应；STEP 无配合时明确缺失，不自动添加。
3. 在证据足够的一条链上建立可人工确认的固定连接/运动副清单，再考虑刚体合并和拆解规划。行程、导程、接触/碰撞需要额外证据，不由同轴关系推出。

每轮新增能力均追加验收，分别报告离线逻辑、真实协议、Windows Conda 和实际 SolidWorks 的结果。
