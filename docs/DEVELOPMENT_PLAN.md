# 当前进度与下一步

当前0.28.0，52工具、45个功能skill；Windows + 用户已有Conda，不设置人工复核。

有原生配合时，可以读取来源、补齐已支持的几何信息并求解单链瞬时约束。没有配合时，新几何分析可根据目标轴线、平面样点和距离提出竞争解释，明确缺口；有界补距离、面目录与局部探测后可重算解释。模板可省略，几何候选不会伪装成原生配合或目标DOF。

## 下一步

1. 用本机真实target/check/index跑几何分析，取得源报告、候选、停止原因和耗时。测试升降机是否有可用配合、哪些候选轴/面具有真实支持，应以这些原始结果为准。
2. 扩展有限几何验证：区分轴线对齐与有限孔轴啮合、端面保持与一般近距离，为旋转/滑动/固定解释增加可检查的支持或反证。当前静态样点不能证明接触持续性、行程或自由运动。
3. 再实现受控小步运动、状态恢复与干涉验证，利用真实观测排除竞争解释。候选未被证明时不写死类型或据此执行拆卸；无法验证的部分在结论列风险。
4. 有配合模型按实际报告扩展距离/角度等约束类型；几何解释、原生约束求解、验证执行保持独立，不一次铺开整机仿真。
