# 当前任务：连接 SolidWorks 并读取组件树

日期：2026-11-09。执行环境：用户另一台已安装 SolidWorks 的 Windows 电脑，用户使用 OpenCode 进行本地开发。

## 本轮交付

只做一个可以实际运行和核对的小功能：连接正在运行的 SolidWorks，读取当前活动文档，导出基本信息和装配组件树。

测试模型已经在 `examples/three_servo_lift/three_servo_lift.zip`，内含 STEP 与参考图。先手动解压并在 SolidWorks 中打开，再开发读取程序；不把自动导入作为本轮前置难题。

## 顺序

1. 读取仓库起步说明，检查 Windows、本地执行环境及 SolidWorks 版本。
2. 用户在 SolidWorks 中打开测试 STEP，记录实际导入方式；若导入为多实体零件，明确报告文档类型并检查导入选项。
3. 用最少依赖实现只读连接已有会话，取得版本、文档名称/类型和可用路径。
4. 对装配文档遍历组件树，保存出现路径、父子关系、名称、可用文件路径和读取状态；重复部件保留不同实例。
5. 写入 `outputs/solidworks_inventory.json`，记录执行方式、组件数量的统计口径及错误/未解析项。
6. 与 SolidWorks 界面的根装配及若干实际组件核对，写出本次已完成和未完成项目。

本轮不要求求解位姿、轴线、配合、自由度或运动范围；这些在组件读取成功后逐步加入。不要把所有远期需求一次实现。

## 完成条件

- 在用户目标电脑上实际连接到其已打开的 SolidWorks 文档。
- 输出的文档类型与当前窗口一致，组件层级可以对应模型树中的实际实例。
- 无文档、错误文档类型、轻化/抑制组件或读取失败均明确表示，不以空列表冒充成功。
- 原始测试包和 SolidWorks 模型保持不变，生成文件保存到 outputs/。
- 给出一条可重复执行的本地命令，以及一份经过核对的 JSON 结果。
