# 当前进度与下一步

当前0.27.0，51个工具、44个功能skill。Windows + 用户已有Conda；原STEP不改，不设置人工复核。

从SolidWorks读取实例及配合后，可以建立目标关系图、补采缺口并求解一条显式链的已支持瞬时约束。根配合来源已独立，不再被圆柱扫描缺失挡住；首次root_mates模式只采一次增强配合，并保留全部保护和历史。默认几何模式保留。模板可选，不能给目标强加关节类型。

## 下一步

1. 在本机复用或取得一条真实候选链的原始report、来源和耗时，区分“无配合”“不支持的配合”“数据缺失”和“采集慢”。不能把本版合成验证当升降机实测。
2. 面向缺少原生配合的STEP，下一项重点是**几何驱动的连接候选与竞争解释**：从已有轴线、平面、近距离/面证据提出可能的固定、滑动或旋转关系；为每个解释列支持/冲突和可执行验证，不直接把几何重合写成真实约束或非空DOF。模板仅作可选解释参考，不要求匹配模板。
3. 有配合的模型按真实报告扩展受支持的距离/角度等约束；已有直接来源与求解层保持解耦。
4. 在证据和运动候选明确后，开发受控小步运动、原位恢复与干涉检查，才进一步推进行程和拆卸路径。当前瞬时零空间不直接作为运动指令。
