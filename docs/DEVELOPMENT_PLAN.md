# 当前进度与下一步

当前MCP 0.13.0，34个工具、27个独立功能skill。Windows + 用户已有Conda；原始STEP保持不变。默认自动完成流程，不设置人工复核门槛；不确定信息在结论列风险。

## 本轮：小型模板库与自动验证基线

- 8个ForgeCAD/SimReady资产的真实结构摘录，固定源版本、许可、哈希与修改说明。6个reference、2个heldout；reference中2个没有关节，作为缺信息负例。
- 目录检索、USD结构提取、已有对应关系下的图评分分别为独立工具和skill。解析保留刚体、关节类型、局部/世界轴线、锚点、限位与未知耦合。
- 自动验收覆盖全部参考提取、缺边、类型错误、映射缺失和错误后恢复。它验证解析/评分链路，不能代表目标STEP的识别准确率。
- 移除默认人工复核入口；旧cad_apply_chain_review仅作历史文件兼容，自动分析不调用它。

## 下一步：把目标SolidWorks证据映射到模板

1. **目标特征适配器**：把现有空间清单、圆柱轴线、根配合、距离/局部面证据整理为统一实例图，保留单位、坐标、来源哈希和缺失项。无需重写COM采集层。
2. **子图候选匹配器**：将参考结构抽象为角色与连接模式，结合轴线、几何关系和层级，输出一条升降链的多个匹配候选及实例对应；对缺失/冲突证据降级，避免按名字硬套模板。匹配评分先作为可解释排序分数，不称统计置信概率。
3. **最小闭环**：在独立参考样例上用隐藏关节标签的输入评估恢复结果，再应用于目标STEP证据。识别结果与输入真值隔离，记录heldout使用；分别报告刚体/连接/关节类型、轴线和未知覆盖。当前图评分只覆盖连接与类型，其余指标随后独立补齐。
4. **之后**：据候选构建刚体与关节草案、自动冲突检查、三条重复链一致性；最后才开发运动、干涉和拆卸路径验证。导程、行程、限位不能从参考资产直接复制到目标模型。

MCP提供确定性能力，skill负责流程选择和按需补证；数据模板独立维护。始终输出当前最有依据的结果、替代假设和风险，信息不足也不等待人工判定。代码测试、真实协议、参考模型解析与用户SolidWorks实测分别记录。
