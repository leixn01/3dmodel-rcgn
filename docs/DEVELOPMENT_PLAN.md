# 当前进度与下一步

当前 MCP 0.11.0：29 个工具、23 个独立功能 skill。Windows + 用户已有 Conda，原始 STEP 不变。[模型实测进度与已用工具](MODEL_PROGRESS.md)单独记录。

## 本轮完成

- sw_component_faces：读取一个零件实例的面目录、平面/圆柱参数、面积、UV 范围、面朝向和持久引用。
- sw_probe_face_pair：解析两个指定有限面，从明确种子交替查询面上测点，输出局部间隙及朝向修正后的法向。支持平面/圆柱，零件定义按实例变换放置。
- cad_review_face_contacts：离线重算并校验原始坐标/法向/来源，按显式毫米和角度阈值整理面级候选。
- 三个独立 skill 按文件交接，入口与细节分开；不强制依赖配合、圆柱轴线或组件距离采集链。

本轮没有给“全局最小面间距”或“真实接触”作证明。局部迭代收敛只表示点位置稳定；大测点间隙不能排除其他部位接近，装配级切除也尚未参与。

## 下一步

1. 按 [0.11.0 验收](MCP_ACCEPTANCE.md#0110具体面间隙与法向)，在升降机上选择一对导向/传动相关零件，先核对面身份、有限面测点、根坐标与法向，收集真实原始 JSON 和耗时，修复实机兼容问题。
2. 将一条升降链的实例/角色、配合、组件距离与局部面证据整理为可人工确认的连接清单；候选、未知、冲突分别保留。确认前不自动合并刚体或生成运动副。
3. 根据实测缺口再扩展装配上下文有限几何、全局间隙/干涉检查。之后才开发刚体/运动副确认、拆卸方向和碰撞路径校核。

每轮保持准确参数、原始来源/范围/错误和人工核对记录。当前仍不移动组件、不编辑配合、不自动执行拆卸。
