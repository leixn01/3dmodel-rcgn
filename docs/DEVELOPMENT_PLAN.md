# 当前进度与下一步

当前 MCP 0.4.0：16 个工具、10 个独立功能 skill。新增软件自动启动，已有组件层级、位置/变换、近似包围盒、选择和显隐。后续只面向 Windows；用户此前仅确认打开模型可用，其余能力仍需实机验证。

## 先完成一次端到端联调

不手动启动 SolidWorks，直接让 OpenCode 执行“启动软件 → 打开仓库 STEP → 读取空间清单 → 抽查三个实例”。按 [0.4.0 启动验收](MCP_ACCEPTANCE.md#040自动启动-solidworks) 检查冷启动、已有会话复用、重复调用，以及退出 OpenCode 后软件仍保留。再按 0.3.0 清单核对坐标与近似边界。遇到实机兼容问题先修复，不把协议测试当作全部通过。

## 下一步开发：一条升降链的零件分组

1. 利用已核对的实例树和空间清单，选择一条升降链，生成“固定基体 / 移动平台 / 传动相关件 / 待确认”的分组候选；保留每个完整实例路径和判断依据。
2. 在 SolidWorks 里逐个选中或隐藏/恢复候选件，帮助人工核对，记录确认或修改结果；不因名称或空间相邻直接认定它们是同一刚体。
3. 输出可修改的分组 JSON 和未知参数清单。之后再补配合/轴线证据，逐步识别运动关系，最后考虑移动组件与自动拆解。

这一阶段的验收目标是“能指出每个零件属于哪组、为什么这样分，并能纠正”，不是直接让整机自动运动。导程、行程、约束没有证据时保持未知。完整设计见 [路线图](ROADMAP.md) 和 [数据契约草案](DATA_CONTRACT.md)。每次新增功能继续补调用方法、预期结果与实机核对步骤。
