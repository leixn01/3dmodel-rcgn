# 当前进度与下一步

当前 MCP 0.8.0：22 个工具、16 个独立功能 skill。Windows + 用户已有 Conda 环境，原始 STEP 保持不变。

## 本轮完成

- sw_mate_inventory：独立读取活动根装配的配合特征，保留抑制、回滚、特征报错及未知状态；只在对象身份核对后映射根实例，实体参数保留根装配上下文。不读取子装配内部配合。
- cad_review_connections：用已有文件，将几何候选与配合关联为实例对复核清单，区分未抑制记录、抑制/报错、未知和仅有几何候选。不将无特征错误称为求解有效或运动副确认，也不宣称已匹配到相同面。
- 所有 skill 采用职责说明 → 简短流程 → 按需参考文件。采集、几何计算、角色分组与连接复核独立；已有文件足够时不启动 COM。

按 [0.8.0 验收](MCP_ACCEPTANCE.md#080配合状态与连接复核) 核对根配合及连接清单。测试 STEP 若没有配合，正确结果是空根配合列表/仅几何证据；非空与抑制案例需用户已有可核对装配，不能把空列表当所有新能力通过。

## 下一步

1. 在真实升降链核对配合记录与候选实例，保留未映射和子装配内部范围缺口。
2. 独立增加配合实体到几何面的对应证据；再处理子装配实例/配置上下文与有效求解状态，避免把同实例对的另一处配合误配到圆柱候选。
3. 证据足够后形成可人工确认的连接/运动副清单，再考虑刚体合并、行程与拆解规划。当前仍不移动组件、不编辑配合、不自动拆解。

每轮新增均保留准确参数、原始 JSON、范围、错误与实机核对记录；模拟测试和 Windows Conda CI 不代表 SolidWorks 实机已通过。
