# 当前进度与下一步

当前MCP 0.24.0，47个工具、40个功能skill。Windows + 用户已有Conda；原始STEP保持不变。自动处理可完成部分，未知与风险写在结论，不设置人工复核。

## 当前流程

读取组件/配置/位姿与配合/几何 → 指定链和目标图 → 条件刚体与目标关系草案 → 局部约束分析 → 有界补采、回填与索引 → 独立局部瞬时运动求解。模板可选，仅提供类比。

0.24新增独立cad_solve_local_constraints：把精确绑定的有效lock、同心轴、重合平面组成缩放后的速度约束矩阵，计算独立约束秩、剩余瞬时方向及纯平移子空间。可处理多轴、多平面和斜面组合，报告相关方程、几何冲突、缺口与数值敏感性。

原0.23补采流程保留：缺引用面/LockRotation才安排一次增强读取，全部保护调用计预算，基础/增强及面探测共享4轮。完整无配合、已尝试增强、不支持类型不能靠重复扫描解决。求解继承索引及轮数，离线不重置历史，原约束分析仍是规划输入。

## 当前边界

局部瞬时维数只属于当前建模假设；目标类型仍unknown、DOF仍null，不自动覆盖草案或确认刚体。不同源快照分别求解，不跨源拼约束。无可用配合是未知，不是6个自由运动方向。

STEP没有保留配合时不会创造约束。名称、近接触、同轴外观或bench_vise swivel不提供目标类型。距离/角度/限位、螺旋/齿轮/路径配合、子装配内部关系、跨组件闭环及碰撞尚不求解。

## 下一步

1. 增加**单条机构链的多组件约束组装与闭环一致性检查**：统一快照/坐标，明确参考组件，计算链级剩余运动和哪些局部方向被其它连接限制；缺失或冲突保留，不跳到整机机械确认。
2. 用本机升降链原始文件核对“端座—导轨”等关系。无配合STEP继续保留几何多解释，识别需要的证据能力，不强制用模板凑出关节。
3. 链级结果稳定后再扩展受支持配合类型、受控运动和干涉检查，最后规划拆卸顺序与路径。

验收入口：[0.24.0](MCP_ACCEPTANCE.md#0240局部瞬时约束求解)。分析、求解、规划、执行、回填和索引分别组织，入口保持简短，细节按需读取。
