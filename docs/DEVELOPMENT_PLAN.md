# 当前进度与下一步

当前 MCP 0.12.0：31个工具、25个独立功能skill。Windows + 用户已有Conda，原始STEP保持不变。[模型实测进度](MODEL_PROGRESS.md)与开发能力分开记录。

## 本轮完成

- cad_build_chain_evidence：按显式2–50叶实例范围汇总角色、轴线/根配合、组件距离和局部面证据。重算来源及哈希，保留所有实例对、未知、边界联系和需要核对的差异。
- 根配合即使没有对应的轴线候选，也会在准确映射到两个实例时纳入；不伪造轴线证据，多实体/未映射配合保留来源缺口。
- cad_apply_chain_review：将明确人工确认/否定/待查/冲突意见绑定到基础清单SHA256，记录人员、时间、理由和依据。声明与CAD验证分开，源partial不清除，不自动合并/移动。
- 两个独立skill按文件交接，已有来源时离线执行；没有证据也能生成保留未知的草案。

## 下一步

1. 在用户SolidWorks电脑选一条升降链，用真实空间/分组和少量配合、距离、面证据生成清单；按[0.12.0验收](MCP_ACCEPTANCE.md#0120机构链证据清单与人工复核)核对范围、缺口和人工意见。当前尚未取得该模型完整真实复核结果。
2. 基于明确的人工连接声明，生成可审查的刚体分组草案及关节参数待补表，保留原始实例映射、未知轴线/行程/限位；先不修改CAD。
3. 补齐真实几何与运动参数后，再开发关节/路径校核、拆卸方向与碰撞检查。人工作出的关系声明不替代求解和运动验证。

每轮保留原始来源、范围、错误及窗口核对；测试替身、真实协议、Windows CI与实际模型验收分开。
