# 当前进度与下一步

当前MCP 0.21.0，45个工具、38个功能skill。Windows + 用户已有Conda；原始STEP保持不变。不设置人工复核，未知与风险在结论说明。

## 主流程调整

先读取目标组件、配置/位姿、配合、距离和具体面证据，再整理关系及条件刚体分组。cad_draft_joints默认不加载模板，给每组目标关系保留约束特征、几何候选、冲突或证据不足；现阶段目标关节类型unknown、自由度null，不能因为名称像导轨就赋prismatic，也不能因为台钳模板有swivel就赋revolute。

目标关系草案可以独立进行检查、只读补采、兼容回填、比较与索引续轮。具体面和轴线继续由原始来源支撑；缺证据的关系仍保留，不受模板窗口筛除。

模板是旁路的可选类比：需要时明确选择参考，比较结构/轴线，解释竞争关系或后续待查项。参考类型和DOF只放reference字段，不能决定目标类型、刚体分组、运动轴/行程。没有合适模板无需勉强套用；模型外观、语义名称和模板分数都不替代目标机械证据。

## 本轮修复和边界

- 修复默认模板驱动、类型/DOF继承以及无模板无法形成后续草案的问题，增加独立目标关系覆盖预算。
- 保留旧版草案/check/index的版本重放；更新结论从原rigid source生成新文件，不能修改旧字段/哈希。
- 修正完整面probe的条件回填提示与包版本号不一致；不增加COM接口或MCP工具。
- 局部近点、同轴、活动配合特征仍不能独立证明真实接触、刚体或剩余自由度。尚无约束求解、受控运动试验或拆卸路径验证。

## 下一步

1. 加强目标配合引用到具体实例/面的绑定，整合同一实例对上的多个约束，明确哪些运动约束已有目标依据、哪些仍缺失；优先检查与候选解释相反的证据。
2. 将几何与约束证据分开，后续在可验证的求解/运动结果基础上确定关节类型与自由度。不能用更多模板或提高相似度阈值替代这一环节。
3. 用用户电脑的真实单条升降链验证完整输出，再扩展跨链一致性与整机分析。真实本机文件缺失时保留未知，不伪造识别率或拆解进度。
