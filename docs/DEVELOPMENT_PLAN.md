# 当前进度与下一步

当前MCP 0.18.0，44个工具、37个功能skill。Windows + 用户已有Conda；原始STEP保持不变。不设置人工复核，未确定信息在结论说明风险。

## 本轮完成：补充观测关联与有界复用

- cad_index_evidence离线重放执行记录与当前草案检查，将完整采集、失败/部分尝试关联到组件、组件对、发现与返回的关节候选。索引保留每条原始来源；面目录和单实例约束可被后续规划复用。
- 顶层固定标志、附属配合记录和面目录提供候选上下文。全部端点成员均有一致fixed=true时，对运动假设给出配置冲突提示；不据此确认或删除关节，不把引用名称猜成根实例。
- cad_plan_evidence_tasks可接收evidence_index_path。完整空结果同样复用；失败/部分尝试不自动重试或扩大预算。返回collect/stop及原因，没有新采集时不再执行只有保护检查的空计划。单条显式来源链最多4轮。
- 新索引有独立skill，规划、执行、回填和比较继续各自解耦。详细字段按需读取；无新增COM接口或CAD修改操作。
- 修正Windows测试中临时目录短路径/长路径比较；逐步执行增加有容量限制的计划重放缓存，每次仍验证全部输入哈希及参考资源，变化即拒绝。

## 当前边界

索引绑定原始文档和完整实例范围/位姿；变化后必须更新空间快照及依赖。只认识显式传入的执行链，不扫描outputs猜历史，不证明采集过程中的几何原子性。

关联不重排候选分数或求解运动。单实例配合名称尚无可靠根实例身份，面目录不选择配对面和测点；本轮只将上下文对齐到已有候选并控制采集。停止补采仍可能保留冲突、未知自由度/行程及搜索缺口。

开发环境未连接用户SolidWorks；测试替身、真实MCP协议和Windows CI不代表该升降机完成真实拆解。整机自动划链、运动/干涉和拆卸路径尚未实现。

## 下一步

1. 基于现有配合持久引用与有限面目录，自动生成可验证的面配对候选和测量任务；明确身份、预算及种子来源，不靠面类型或同轴直接判接触。
2. 把实际面测量结果重新关联到具体关节候选，报告支持、冲突与未测范围；继续复用索引，避免无效重复调用。
3. 在用户本机形成一条真实升降链的完整记录，再扩展机构链划分、跨链一致性和运动/拆卸验证。

本机按[0.18.0验收](MCP_ACCEPTANCE.md#0180证据关联复用与停止)使用已有check与执行记录；缺少输入交接对应独立能力，不要求人工填映射或确认机械关系。
