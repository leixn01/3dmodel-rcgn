# 当前进度与下一步

当前 MCP 0.10.0：26 个工具、20 个独立功能 skill。Windows + 用户已有 Conda 环境，原始 STEP 保持不变。

## 本轮完成

- cad_proximity_candidates：从完整空间清单的近似包围盒生成待测组件对，显式控制范围与预算，保留缺失几何。
- sw_component_distance：只读两个已解析零件实例的最小距离和最近点，不要求有配合；一次调用测一对。
- cad_review_proximity：离线区分近接触候选、已测间隔、测量失败和未测，绑定原始文件/实例/配置/位姿。
- 三项能力各有独立 skill；简短入口与详细参考分开，不强制加载完整流程，不与配合面身份混用。

先按 [0.10.0 验收](MCP_ACCEPTANCE.md#0100组件距离与近接触候选) 对 2–5 个真实零件逐对测量，与 SolidWorks 窗口核对距离、最近点和只读状态。零距离仍不能区分接触、干涉或包含。
