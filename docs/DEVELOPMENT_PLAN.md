# 当前进度与下一步

当前 MCP 0.3.0：15 个工具、9 个独立功能 skill。已增加单实例空间查询和整机空间清单，保留实例层级、根/父坐标变换、原点位置、近似包围盒与读取错误。用户此前仅确认打开模型可用，新能力待实机验证。

## 先验收空间读取

在安装 SolidWorks 的 Windows 电脑，按 [0.3.0 验收清单](MCP_ACCEPTANCE.md#030组件空间信息) 核对至少三个实例，覆盖重复文件和子装配。重点核对米/毫米换算、嵌套变换、近似包围盒与缺失数据；保存真实原始 JSON 和人工核对结论。STEP 若导入为多实体零件，应记录阻塞，不把实体当作组件。

按同一清单继续补验隐藏/恢复基准面、选择与组件显隐等已有功能；记录实际软件版本、导入类型和失败项。先修复实机发现的问题，再进入下一步。

## 下一步：从一条升降链做分组

基于已核对的空间清单，先选一条升降链，由人工确认固定基体与移动平台，再增加分组及运动关系候选。名称与空间邻近只作线索；轴线、配合、导程、行程没有证据时保持未知。先形成可复核的分组结果，再考虑移动组件或自动拆解。

后续每次新增功能都随版本补充“怎么调用、检查什么、怎样算通过”的验收项。完整设计保留在 [路线图](ROADMAP.md) 和 [数据契约草案](DATA_CONTRACT.md)，不把远期功能一次实现。
