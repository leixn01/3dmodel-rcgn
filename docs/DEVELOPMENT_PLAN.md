# 当前进度与下一步

当前MCP 0.16.0，40个工具、33个功能skill。Windows + 用户已有Conda；原始STEP保持不变。不设置人工复核，未确定信息在结论说明风险。

## 本轮完成：草案检查与补采规划

- cad_check_joint_draft重放全部来源和候选，区分实例归属/端点结构错误、有效锁定与相对运动假设的证据冲突、参考轴向差异、竞争类型和覆盖缺口。结构检查通过不证明机械关系正确。
- cad_plan_evidence_tasks生成准确只读调用及依赖、优先级、前后文档/位姿核对、原始envelope保存路径。预算包含保护步骤，整项任务无法容纳就延期；完整已有证据复用，不因空/模糊结果反复扫描。
- 两个独立skill和工具；纯算法在cadkin/followup，来源重放/文件边界在tools/followup。计划执行、原始采集、证据回填仍各自独立；不新增COM操作。
- 缺少自由度、行程/螺距、配对面选择或求解能力时明确记录unresolved_findings，不把采集成功当作问题解决。heldout来源暴露继续保留。

## 当前边界

计划只保存JSON，executed=false。Agent后续可按任务调用已有只读采集能力，但本轮没有自动执行器，也没有自动消费新envelope、重算依赖并比较前后候选的闭环。单实例约束只作补充上下文；面目录不自动确定配对面和测点。

文件重放检测来源/派生变更，不证明CAD原子快照。执行前后仍需核对文档、配置、dirty、实例身份与位姿；不通过就重采空间快照，不改旧token/哈希绕过。不同候选的转动/移动解释不可合成同时成立的约束，也不能凭评分确认刚体。

开发环境未连接用户SolidWorks；离线验收与显式替身调用不代表该升降机已完成真实拆解。

## 下一步：受控执行与证据回填

1. 增加独立的只读任务执行/记录能力，自动验证前后上下文，串行执行有预算的任务，保留成功、部分、失败与延期状态；不盲目重试，不修改CAD。
2. 校验新增原始envelope，按来源依赖重算关系、清单、目标图、分组、草案与检查，保留旧版本；单实例约束需先补足可验证的关联方式。
3. 比较前后候选与发现，区分“新增证据支持”“仍存在”和“因输出范围变化未再出现”，不把条目消失当作物理问题已解决。
4. 先在用户本机完成一条真实升降链的可追溯结果，之后再扩展跨链一致性、运动/干涉、行程耦合与拆卸路径。

本机按[0.16.0验收](MCP_ACCEPTANCE.md#0160草案检查与补采规划)操作；缺少输入时使用对应独立能力，不要求人工填映射或确认机械关系。
