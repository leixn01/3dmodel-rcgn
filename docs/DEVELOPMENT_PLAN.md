# 当前进度与下一步

当前 MCP 0.9.0：23 个工具、17 个独立功能 skill。Windows + 用户已有 Conda 环境，原始 STEP 保持不变。

## 本轮完成

- 圆柱采集可选保存并回读持久面引用；默认普通轴线读取保持原方式。
- sw_match_mate_faces：独立只读采集根配合，将已保存的零件面解析到当前组件实例，再以 CAD 对象身份比较配合引用面。保留不支持、非面、范围外、失效与截断状态。
- cad_review_connections：离线区分实例对关联与具体候选面配对，配合抑制/报错状态独立保留。不会因为面相同就确认接触、运动副或剩余自由度。
- 新增 mate-face-matching；圆柱采集、在线面核对、离线复核按文件交接，各 skill 简短入口和参考文件继续按需加载。

先按 [0.9.0 验收](MCP_ACCEPTANCE.md#090配合引用面核对) 实测少量零件与一条已知根配合。STEP 无配合时记录空结果和未测试分支，不能将其当成面匹配成功。

## 下一步

1. 收集真实 SolidWorks 的面引用解析/实例映射结果，先处理实机兼容与范围缺口。
2. 对没有配合信息的 STEP，独立增加有限几何的邻近/接触候选证据，筛掉仅轴线相同但远离的组合；不把接触候选直接当机械连接。
3. 后续再扩展子装配内部配合、配置上下文、求解有效性与人工确认连接清单；证据足够后考虑刚体合并、行程与拆解规划。

每轮新增保留准确参数、原始 JSON、范围、错误与实机核对记录。模拟测试、真实协议与 Windows Conda CI 分开记录；当前仍不移动组件、不编辑配合、不自动拆解。
