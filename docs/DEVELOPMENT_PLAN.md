# 当前进度与下一步

当前 MCP 0.6.0：19 个工具、13 个独立功能 skill。启动配置与命令统一使用用户已有 Conda 环境的 python；会话查询返回实际解释器路径。此前的分页、显示修复和候选分组保留。

## 本次新增：分组的证据读取

- `sw_component_constraints`：读取一个实例的顶层固定标志、关联配合、引用组件名称和原始实体参数。嵌套固定状态不猜；配合坐标上下文不明时不转换，未读取活动/抑制状态，不计算自由度。
- `sw_component_cylinders`：读取一个匹配配置的零件定义中的解析圆柱面，输出实例根坐标下的轴线/半径。原始参数、变换和限制一起保留；不包含装配级切除，不认定孔/轴或运动副。

这一步提供可核对事实，现有分组仍为独立的角色候选和人工复核流程，不自动把 API 标志或几何轴线升级为已确认关系。

## 接下来：在一条真实升降链上核对证据

1. 按 [0.6.0 验收](MCP_ACCEPTANCE.md#060conda与约束轴线证据) 核对 Conda 解释器、顶层/嵌套固定状态、配合空值与失败、一个已知圆柱件和重复实例。0.5.0 的实机修复复测仍保留，不能默认已通过。
2. 选择一条实际子装配范围，收集已核对的角色候选、约束记录和轴线文件，明确尚缺的上下文及几何差异。若 STEP 没有配合，就记录为缺失证据，不自动添加约束。
3. 下一轮实现同轴/平行等几何关系候选与证据关联，先确定合理公差和坐标上下文，再结合配合活动状态判断固定连接或运动副。行程、导程、碰撞和自动拆解继续等待独立证据，不从圆柱面半径推断。

原始 STEP 保持不变；结果写 outputs 新文件，用户确认后才记录角色修正。代码测试、真实协议和实机窗口核对分别报告。
