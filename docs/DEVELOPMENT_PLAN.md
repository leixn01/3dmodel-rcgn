# 当前进度与下一步

当前0.25.0，49个工具、41个功能skill。Windows + 用户已有Conda；原STEP不改，不设置人工复核。

## 当前流程

读取结构/配合/几何 → 指定链和目标图 → 条件分组与目标关系草案 → 局部约束分析 → 有预算批量补采、回填和索引 → 组件对/单链瞬时运动求解。模板可选，参考类型不继承给目标。

本版联合2–20个实例的有效根配合，每源快照单独组装约束，显式参考只去掉共同刚体运动。可报告闭环新增限制、重复方程、各实例耦合方向；不连通、缺失/截断、冲突及数值敏感保留未知。

执行侧新增批次，将多次agent往返改为服务端串行调度，原单步保护/receipt/停止和4轮历史不变。返回摘要、完整记录存盘；计时区分工具调用与编排开销。常规按功能和具体缺口加载说明，不重复扫描/读取。

## 当前边界

单链结果仍为当前姿态一阶模型，不是目标机械DOF或实际可运动结论。无配合STEP不能靠模板、名字、同轴或近接触凭空生成约束。子装配内部关系、距离/角度/限位/齿轮/螺旋配合、驱动、碰撞及有限路径未求解；当前没有本升降机的新实机验证数据。

## 下一步

1. 依据本机单链与计时报告定位剩余证据缺口和耗时点；分别处理模型约束与MCP调度，保持可回放数据和停止历史。
2. 扩展受支持的目标配合约束（优先可明确绑定的距离/角度类型），补充闭环几何一致性诊断；无配合STEP继续保留几何竞争解释，明确需要的新证据能力。
3. 完善受控的小步运动与状态恢复、干涉检查后，再规划有限行程及拆卸顺序/路径。不能以当前瞬时零空间直接驱动模型。
