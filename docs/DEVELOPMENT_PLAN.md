# 当前进度与下一步

当前MCP 0.22.0，46个工具、39个功能skill。Windows + 用户已有Conda；原始STEP保持不变。自动处理可完成部分，未知与风险写在结论，不设置人工复核。

## 主流程

目标组件/配置/位姿 → 配合和几何证据 → 指定链和目标图 → 局部约束组合分析及条件刚体/关系草案。模板仍是旁路类比，不决定目标类型或分组。

0.22新增独立cad_analyze_constraints，从目标图重放原始配合，逐实例对、逐源快照组合约束。sw_mate_inventory可选读取引用面的解析类型、根参数、持久身份以及同心配合的LockRotation。输出固定/旋转/滑动的局部候选、支持记录、缺口和矛盾；近接触、同轴外观和名称不提供约束。

两条重合轴不能算成独立约束；不同mate快照不拼接；抑制、报错、未知/多实体引用保留。参考类型不会进入目标字段。局部规则支持不等于整机可运动，target_joint_kind仍unknown、DOF仍null。

## 本轮边界

约束报告独立于draft/check，尚未自动修改刚体分组或草案。既有补采、回填、比较、索引和4轮停止机制继续使用；增强配合选项和新报告缺口尚未接入自动规划器。报告只提出缺口，不暗中触发CAD或重置历史。

已实现显式lock、同心圆柱+锁定旋转、不同位置平行同心轴、同心轴+沿轴重合平面的局部规则。距离/限位配合、斜向平面、非平行轴、复杂/多实体配合及子装配内部约束仍不求解。

## 下一步

1. 让有界补采计划消费约束报告的具体缺口，精确安排增强配合采集，沿用原receipt/索引和轮数，再重算约束候选；避免重复读取基础mates而没有补上关键字段。
2. 在完整、精确绑定的目标约束上开展局部约束秩/剩余运动分析，随后处理跨组件回路与整机一致性。数学自由度与受控运动验证分别记录，不把候选规则当求解器。
3. 使用本机单条升降链文件核对“端座—导轨”等关系；STEP若无配合，保留几何候选和缺失证据，不用台钳模板补造约束。之后才扩展受控运动和拆卸路径。
