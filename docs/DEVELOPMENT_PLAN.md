# 当前进度与下一步

当前 MCP 0.5.0：17 个工具、11 个独立功能 skill。修正显示常量加载；组件显隐只遍历一次并取消强制重绘；空间数据按页读取，CLI 自动汇总。新增离线组件分组工具，输入为实际导出的完整实例空间 JSON。

## 当前分组能做什么

按完整实例路径，生成固定基体、移动平台、传动/导向相关件和待确认四类角色候选。名称规则保留命中依据，父子层级和近似盒中心距离辅助复核；匿名编号或冲突名称不会被强行分类。同文件多实例分别保留，只分配叶实例，子装配容器另计。支持指定子装配范围和带源文件哈希的人工修正，结果写入 outputs 新文件，不改 CAD。

## 下一步：验证一条真实升降链

1. 按 [0.5.0 验收](MCP_ACCEPTANCE.md#050修复与组件分组) 复测用户报告的三个问题；分页导出全部实例，与当次组件树数量和路径集合核对。
2. 先生成整机候选，结合实际实例树选定一条升降链的范围；逐个选择实例核对，用户明确确认后保存复核记录。匿名名称多时允许大部分 pending，不能把规则运行成功当作准确识别。
3. 以已确认的角色和未知项为输入，下一轮增加配合/轴线等证据读取，判断固定关系与运动副，再考虑刚体分组、行程和组件运动。没有证据的导程/行程仍未知。

这次完成的是可追溯、可纠正的角色候选分组。真实模型的分组准确性和大装配响应时间需在用户 Windows + SolidWorks 2025 上复测；离线替身不证明这些结果。软件自动启动仍按 0.4.0 清单验收。
