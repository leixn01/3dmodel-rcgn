# 后续路线图：自动数模运动关系构建

日期：2026-11-12。状态：后续设计参考。当前只执行 DEVELOPMENT_PLAN.md 中的最小任务；本文件不作为本轮完整开发清单。

## 1. 我们要做什么

目标是把已经分件的工业 CAD 装配，转换为能编辑、能解释、能驱动验证的机电模型。核心输出包括：CAD 实例身份、刚性运动分组、运动约束图、关节轴线及坐标、参数及依据、驱动与反馈映射。

长期业务主线仍是 PLC 语义安全审查与机电联合验证。本仓库先完成机械侧基础能力，保留 PLC/EPLAN 接口。已有多厂商纯软件 PLC 执行和信号到 PS 的需求前提继续沿用，本阶段不重做整套 PLC 执行器。

## 2. 以 STEP 数模为输入，先验证 SolidWorks 导入

指定原包已下载并核验；当前仓库只保留其中的 `3X Lift Assembly.STEP` 和 `Bosch SSS 08.JPG`，不含 SLDASM、SLDPRT、PLC 或电气工程。

STEP 文件头声明 AP214 / AUTOMOTIVE_DESIGN，导出器为 SolidWorks 2012。**SolidWorks 支持打开和导入 STEP，本样例可以继续沿用 SolidWorks 工作流。** 文本体检看到装配引用、B-Rep 定义及零件名称，但没有识别到运动学简单实体类型。这既不是原生 Mate 提取结果，也不能代替实际导入后的配合检查。

| 输入情况 | 当前路线 | 证据边界 |
| --- | --- | --- |
| 本次 STEP 样例 | SolidWorks 导入后检查实例/几何/配合；可用约束走 A，缺口用 B＋C | 用户已确认打开及多项 API 读取；完整空间清单与几何含义需复测，配合仍待提取 |

## 3. 技术分层

1. **输入适配**：优先在 Windows＋SolidWorks 中导入 STEP，记录软件版本、3D Interconnect/导入选项、装配结构、部件实例、位姿、几何和配合清单。避免将整机作为单一多实体零件导入而丢失可用层级；确需此模式时明确记录损失。需要编辑时保存独立工作副本，不覆盖源 STEP。FreeCAD/OCCT 是开源读取与交叉检查通道，可在没有 SolidWorks 的执行环境中先开发，不能将其结果冒充 SolidWorks 实测。
2. **统一数据层**：独立于具体编辑器的版本化 JSON，分别保存 CAD 实例、刚体、约束、参数和证据。原始事实不可被推断结果覆盖。
3. **推断层**：名称与型号检索、几何空间关系、有限机构模板共同提出候选；确定性工具负责几何测量，Agent 负责关联资料和解释冲突。
4. **编辑确认层**：先做实例选择、分组着色、轴线显示、候选接受/拒绝、参数来源展示、修改保存。可试用 sw2robot 编辑器，但不强制让其树结构成为内部事实格式。
5. **验证与导出层**：在确认范围内逐轴运动，检查位姿、干涉与耦合；导出到选定运行平台。闭环和不能表达的约束必须明确报告。

第一版采用 Python 为主的模块化仓库。避免同时建设多套 CAD 引擎和完整仿真平台；具体版本在集成验证通过后锁定。

## 5. 三独立伺服升降机的首个最小目标

参考图显示三组相似升降结构；名称提供电机、联轴器、丝杆、导轨及滑块线索。它们是识别依据，不足以证明所有真实运动关系。

建议先选其中一组，建立“固定基体—移动平台”的等效直线轴模型，保留所有原始 CAD 实例映射。若确认丝杆、电机转子、联轴器需独立运动，再增加转动副与旋转—直线耦合。导程、传动比未取得证据前不赋值，也不根据型号字符串直接写入参数。

三个升降链的具体实例集合、基体是否共享、相互是否独立、附属机构是否存在额外自由度，均以几何分析、模板结构与自动一致性校核为准。不能为了得到三个关节而硬编码“三独立”结论。

模板分为两级：

- **工艺级模型**：用已确认移动副表达平台位移，适合先做位置与信号验证。
- **机构级模型**：补充丝杆旋转、传动及内部相对运动；工艺级折叠必须记录适用范围，不能用来验证被省略的内部风险。

## 6. 模板与 Agent 的边界

模板描述“哪些角色应存在、需要什么几何和资料、允许哪些关系、还缺什么参数”，不能只靠相似文件名自动确认。几何接触、贴合或同轴也不能单独证明刚性连接。

每个候选保存：输入实例、规则/工具版本、几何量、来源定位、证据强弱、冲突与结论风险记录。Agent 可调用测量工具、选模板、查已提供手册并解释候选；轴线计算、变换组合和运动校核交给确定性代码。

原始 CAD 固定状态、求解剩余自由度和工程真实自由度分别保存。几何可行范围、机械硬限位、控制器软限位与工艺目标使用不同字段。

## 7. 验收方法

不以单个“识别率”覆盖所有问题，至少分别报告：

- 实例与层级完整性、重复实例误绑定数量。
- 刚体分组的误合并、误拆分及 pairwise precision/recall。
- 关节类型、连接两端、轴线位置误差、轴向角误差与正方向。
- 单位、参考系、零位、机械范围、控制范围及耦合关系。
- 有证据的自动确认覆盖率、候选覆盖率、错误确认率、自动冲突检出率与未知覆盖率。
- 保存/重载一致性、导出损失、运动及碰撞检查结果。

轴线距离和角度阈值在了解模型尺度、导入公差和使用需求后写入基准；不提前捏造通用合格阈值。用复制样例做缺信息对照，不修改唯一原始输入。
